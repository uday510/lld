Abstraction is a technique used in object-oriented programming that simplifies the program's structure. It focuses only
on revealing the necessary details of a system and hiding irrelevant information to minimize its complexity. In simpler 
words, we can say that it means to show what an object does and hides how it does it.

Advantages of abstraction
The following are some advantages of abstraction:

It reduces the complexity of the system from a user's perspective.

It makes the code extendable and reusable.

It refines the modularity of the application or the system.

It makes the code more maintainable.
